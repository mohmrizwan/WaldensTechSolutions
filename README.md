# 🚀 Walden Tech Solutions

A modern full-stack agency portfolio website built using the MERN stack. The project includes a responsive client-facing portfolio, a secure admin dashboard for content management, and a RESTful backend API.

## 🌐 Overview

Walden Tech Solutions is a digital agency portfolio designed to showcase services, projects, testimonials, and team members while providing an admin panel to manage all website content dynamically.

## ✨ Features

### 👨‍💻 Public Website
- Responsive landing page
- Dynamic Hero/Banner section
- Services section
- Projects portfolio
- Team members
- Testimonials
- Contact form
- Modern UI with React

### 🔐 Admin Panel
- Secure Admin Authentication
- Dashboard
- Banner Management (CRUD)
- Services Management (CRUD)
- Projects Management (CRUD)
- Team Management (CRUD)
- Contact Message Management
- Profile Settings
- Password Settings
- Website Settings

### ⚙️ Backend API
- RESTful API
- JWT Authentication
- Role-based Authorization
- MongoDB Database
- Cloudinary Image Upload
- Input Validation
- Error Handling

# 📦 Installation

## Clone Repository

```bash
git clone https://github.com/mohmrizwan/WaldensTechSolutions.git
```

## Install Dependencies

### Frontend

```bash
cd frontend
npm install
```

### Admin Panel

```bash
cd admin-panel
npm install
```

### Backend

```bash
cd backend
npm install
```

---

# ▶️ Run Project

### Backend

```bash
npm run dev
```

### Frontend

```bash
npm run dev
```

### Admin Panel

```bash
npm run dev
```

---

# 🔑 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=
MONGO_URI=
JWT_SECRET=

CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```

> Never commit your `.env` file to GitHub.
